# HERITZ TAILOR

Responsive website adapted from the approved Figma design. Desktop 1280px, tablet 800px, mobile 375px reference layouts; fluid layouts between widths.

Static HTML, CSS and ES modules. All 54 site photos are stored locally in assets/. Shared navigation, seven page views, gallery filters, photo dialogs, keyboard/swipe controls and reservation/contact links are included.

GitHub Pages automatically publishes the main branch from the repository root. No build step is required. Website: https://5banjang.github.io/heritz-preview/
